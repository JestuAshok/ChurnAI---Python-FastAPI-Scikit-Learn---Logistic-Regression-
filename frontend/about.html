    About the ChurnAI Project

    Machine learning details, system architecture, and tech stack details

    Customer Churn Prediction Platform

    Customer churn—the rate at which subscribers discontinue their services—poses a major challenge to contract-based telecom and subscription businesses. Acquiring new customers can cost up to 5 times more than retaining existing ones. This application acts as an executive decision support portal, allowing managers to query churn risk in real-time, inspect analytical cohorts across the customer database, and review action plans to reduce attrition.

    System Architecture & Tech Stack

    Frontend Stack
    HTML5, CSS3 with a custom Glassmorphism grid framework, Vanilla ES6 JavaScript for dynamic DOM updates, and Plotly.js for premium web charts.
    FastAPI Backend
    Python 3 backend featuring asynchronous endpoint handling, Pydantic type checking & schema validation, and automatic error output.
    SQLite Data Layer
    SQLAlchemy Object Relational Mapper connected to an embedded SQLite database (`predictions.db`) for transaction logging and history audits.
    Machine Learning Model
    Logistic Regression model serialized with joblib, operating alongside a StandardScaler mapping 35 features. Optimizations are threshold-driven (threshold set at 0.38).

    Feature Engineering Pipeline

    To match the pre-trained Logistic Regression models, the input data undergoes real-time feature engineering before inference. The system automatically computes 6 mathematical features from user inputs:

    Customer Lifetime Value Calculated as MonthlyCharges × tenure. Maps the total projected revenue contribution.
    Average Monthly Spend Calculated as TotalCharges ÷ (tenure + 1). Smooths spending velocity.
    Total Services Sum of all active service flags (Phone, Streaming, Backup, Security, Tech Support).
    Long Term Customer Binary indicator flag set to 1 if the tenure is 24 months or greater.
    Monthly Contract Binary flag set to 1 if the contract type is 'Month-to-month'.
    Internet Addons Count Aggregated sum of auxiliary internet services (Security, Backup, Support, Streaming) subscribed.
